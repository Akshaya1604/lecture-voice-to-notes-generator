🎓 AI Lecture Voice-to-Notes Generator
📌 Project Overview
This project converts lecture audio into structured notes using Artificial Intelligence.
It generates:
*Full transcript
*Concise summary
*Quiz questions
*Downloadable PDF notes

🛠 Technologies Used
*Python
*Whisper (Speech-to-Text)
*Hugging Face Transformers
*Streamlit
*ReportLab

🚀 Features
*Upload lecture audio (.mp3/.wav/.ogg)
*Automatic transcription
*AI-based summarization
*Quiz generation
*PDF export
*Professional web interface
